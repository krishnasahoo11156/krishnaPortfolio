What is CrisisSync and what technologies does it use?

CrisisSync is an AI-powered real-time crisis response and emergency coordination platform developed by Krishna in May 2026. It classifies incoming emergency incident reports via Gemini AI, calculating automated severity scores, and plots active responses on a live Google Maps tracking interface.

The tech stack includes:

  • Frontend: Flutter (Dart) compiled for web execution.
  • Backend: Firebase services (Authentication, Real-time Database, Cloud Storage).
  • AI: Gemini AI API.
  • DevOps: Containerized with Docker and deployed on Google Cloud Run.
What is StudySync and how does it assist students?

StudySync is an academic productivity dashboard designed to keep students focused and organized. It is built using React.js, Vite, Tailwind CSS, and Firebase, featuring:

  • An intelligent calendar with automated conflict detection.
  • A Pomodoro timer with integrated Web Audio API background soundscapes (rain, white noise, and lo-fi beats).
  • A synced cloud file organizer with folder structures.
  • A task manager with priority tags and deadline indicators.
What is the Autonomous Developer Onboarding Agent?

Built during the Syrus 2026 Hackathon, the Onboarding Agent is an AI platform designed to automate local environment setup and configuration for new developers on day one.

It runs a lightweight node script to check installed system software (Node, Git, Docker), uses Gemini AI to answer onboarding questions, and provides an HR dashboard with Chart.js to monitor new hire progress. The project was built with Next.js, TypeScript, Gemini AI, NextAuth, and Framer Motion.
