## 🚀 Running Locally

This is a **zero-dependency, zero-build static site.** No npm. No bundler. Just open it.

```bash
# Clone
git clone https://github.com/krishnasahoo11156/krishnaPortfolio.git
cd krishnaPortfolio

# Option A — VS Code Live Server (recommended)
# Install the "Live Server" extension → Right click index.html → "Open with Live Server"

# Option B — Python one-liner
python -m http.server 3000
# → open http://localhost:3000

# Option C — Node (if you have it)
npx serve .
# → open http://localhost:3000
```

> **No environment variables. No API keys. No `.env` files.** Works offline after first load.
